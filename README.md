# FER at SemEval-2026 Task 6: Unmasking Political Question Evasions

System code for our SemEval-2026 (ACL) paper on fine-grained classification of
political question evasion.

- BERT baseline and hierarchical RoBERTa ("clear reply vs. rest") classifiers
- Compact multitask encoder for fine-grained evasion classification — **macro F1 0.438**,
  outperforming an instruction-tuned Llama-13B baseline with an order of magnitude
  fewer parameters

**Paper:** [PDF](https://github.com/ma55530/FER-SemEval2026-T6) · ACL Anthology, 2026
**Team:** FER, University of Zagreb — TakeLab
